# SuvoraNova

SuvoraNova is a high-performance, fully-featured e-commerce single-page application (SPA) built with **React**, **React Router**, **Tailwind CSS**, and **Vite**. Designed with a sleek, dark-slate and amber UI, it delivers a seamless, end-to-end online shopping experience without requiring a backend database by leveraging `localStorage` for complete data persistence.

---

## Features

- **Dynamic Product Catalog:** 50-item inventory complete with instant search, category filtering, and multi-option sorting (Price, Rating, Featured).
- **Persistent Shopping Cart:** Fully functional cart system with live quantity adjustments, subtotal calculations, and `localStorage` state retention.
- **Simulated Checkout Flow:** Multi-step frontend checkout supporting detailed shipping address entry, payment details, and instant order success confirmation.
- **Order History Tracking:** Automatically archives completed transactions into local storage, viewable on a dedicated **Order History** dashboard with item breakdowns and receipt details.
- **Modern Responsive UI:** Polished dark-mode layout built with Tailwind CSS, custom focus states, and responsive grid structures.

---

## 🛠️Tech Stack

- **Framework:** React (Functional Components, Hooks like `useState`, `useEffect`)
- **Routing:** React Router DOM (`v7`)
- **Styling:** Tailwind CSS
- **Build Tool & Bundler:** Vite
- **State & Storage Persistence:** Browser `localStorage`
